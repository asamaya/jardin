Bienvenido a la introducción de html

HTML (por sus siglas en inglés, HyperText Markup Language, o Lenguaje de Marcado de Hipertexto ); el cual es lenguaje estándar utilizado para crear y estructurar el contenido de las páginas web.

¿Qué hace y para qué sirve?

  • Estructura el contenido: Funciona como el "esqueleto" o los cimientos de un sitio web, organizando textos, imágenes, videos, tablas y formularios.
  • Usa etiquetas (tags): Emplea instrucciones escritas entre corchetes angulares (como   <h1>   para títulos o   <p>   para párrafos) para indicar al navegador cómo debe interpretar cada elemento.
  • No es un lenguaje de programación: No ejecuta lógica, cálculos ni procesos de datos por sí solo; simplemente define qué hay en la página.

Se complementa con:

  • CSS: Se encarga del diseño visual, los colores y los estilos.
  • JavaScript: Añade la interactividad y el dinamismo.
